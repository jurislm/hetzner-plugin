Quick Setup

Install with Codex CLI by running the two commands above. For other MCP hosts, use the local stdio configuration below:

{
  "mcpServers": {
    "hetzner": {
      "type": "stdio",
      "command": "bunx",
      "args": ["-y", "@jurislm/hetzner-plugin@latest"],
      "env": {
        "HETZNER_API_TOKEN": "your-api-token"
      }
    }
  }
}
Requirements:
  • Requires Bun 1.1+ and a project-bound HETZNER_API_TOKEN; the same token is used for both the Cloud and Unified APIs.
  • For RAM queries over SSH, the server needs a reachable public IPv4 address and the free command. The host needs ssh and a key available through ssh-agent or ~/.ssh; fingerprint verification also requires ssh-keyscan and ssh-keygen.
  • Runs locally over stdio. No remote MCP endpoint or OAuth is provided.
  • Storage Box passwords are sent in plaintext over MCP. Protect MCP session logs and treat one-time credentials returned by actions as secrets.
