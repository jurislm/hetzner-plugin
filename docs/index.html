Quick Setup

codex plugin marketplace add https://github.com/jurislm/hetzner-plugin, then codex plugin add hetzner-plugin@hetzner-marketplace. Or add this server to your own MCP client config:

{
  "mcpServers": {
    "hetzner": {
      "type": "stdio",
      "command": "bunx",
      "args": ["-y", "@jurislm/hetzner-plugin@latest"],
      "env": {
        "HETZNER_API_TOKEN": "your-api-token"
      }
    }
  }
}
One token: Set HETZNER_API_TOKEN once. Cloud and Storage Box requests use the same token.
