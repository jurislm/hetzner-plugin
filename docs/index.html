Quick Setup

For Codex CLI, copy the two commands above. For other MCP hosts, use the local stdio configuration below:

{
  "mcpServers": {
    "hetzner": {
      "type": "stdio",
      "command": "bunx",
      "args": ["-y", "@jurislm/hetzner-plugin@latest"],
      "env": {
        "HETZNER_API_TOKEN": "your-api-token"
      }
    }
  }
}
Requirements: Use Bun 1.1 or later and set HETZNER_API_TOKEN. Tokens are project-bound. This plugin uses local stdio only; it has no remote MCP endpoint or OAuth.
